# Garmin Forerunner 570 MTP Setup on Arch Linux

## Goal

Access a Garmin Forerunner 570 over USB from Arch Linux, both through Dolphin and from the terminal.

---

## 1. Verify USB detection

Connected the watch and checked:

```bash
lsusb

Detected:

Bus 007 Device 005: ID 091e:51da Garmin International

This confirmed the kernel detects the watch.

2. Confirm the watch uses MTP

Ran:

mtp-detect

Initially, it failed because Dolphin/KDE had already claimed the MTP interface:

libusb_claim_interface() reports device is busy,
likely in use by GVFS or KDE MTP device handling already

After releasing the device, mtp-detect successfully identified it:

Manufacturer: Garmin
Model: Forerunner 570 - 47mm
Device version: 1737
Serial number: 0000d740a51f

The device reported:

Interface description contains the string "MTP"
Device recognized as MTP

Storage information:

StorageDescription: Internal Storage
MaxCapacity: 7613612032
FreeSpaceInBytes: 4897898496

Conclusion:

The Forerunner 570 uses MTP.
Linux/libmtp can communicate with it.
The device is not currently in the libmtp device database.
3. Understand Dolphin behavior

Dolphin works, but it does not mount the watch as a normal filesystem.

Dolphin uses KDE's KIO MTP backend.

Checked:

find /run/user/$UID -maxdepth 3 | grep -i mtp

Found:

/run/user/1000/systemd/transient/dbus-:1.2-org.kde.kmtpd5@0.service
/run/user/1000/systemd/units/invocation:dbus-:1.2-org.kde.kmtpd5@0.service

This indicates KDE's MTP daemon (kmtpd5) was handling the device.

Because of this, commands like:

mount

or:

gio mount -li

do not show a normal mounted filesystem.

4. Access the Garmin from the terminal with jmtpfs

Install/use:

jmtpfs

Create a mount point:

mkdir -p ~/mnt/garmin

Mount:

jmtpfs ~/mnt/garmin

Successful mount:

mount | grep garmin

Output:

jmtpfs on /home/heath/mnt/garmin type fuse.jmtpfs

The watch is now accessible like a normal directory:

ls ~/mnt/garmin/'Internal Storage'

Output:

Audiobooks
GARMIN
Music
Podcasts
5. Unmount before unplugging

Always unmount:

fusermount3 -u ~/mnt/garmin

Then unplug the watch.
```
